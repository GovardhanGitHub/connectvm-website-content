## 3. Core Platform Features Grid

**Eyebrow:** EVERYTHING YOU NEED TO SCALE
**H2:** A Complete Cloud Ecosystem Built for Modern Workloads

### Compute Instances
Launch Linux or Windows virtual machines sized for any workload—from lightweight microservices to memory-intensive databases. Scale vertically in clicks or horizontally across availability zones.

### Dedicated & Portable Public IPs
Reserve static IPv4 addresses to your account and map them to any VM on demand. Remap traffic between primary and standby instances in seconds without waiting for DNS propagation.

### Virtual Private Cloud (VPC)
Run your backend databases and internal services on completely isolated Layer-2/Layer-3 private networks. Control ingress and egress routing through managed virtual routers and NAT gateways.

### Persistent NVMe Block Storage
Attach up to multiple terabytes of high-speed block storage to any instance. Expand volume capacity on the fly and move volumes seamlessly between virtual machines.

### Instant Snapshots & Cloning
Capture point-in-time snapshots of your root disks and data volumes before critical updates. Restore instances in seconds or convert snapshots into reusable golden images.

### Granular Security Groups
Protect your infrastructure at the virtual NIC level. Define stateful ingress and egress firewall rules by IP CIDR, protocol, Port, or security group membership—applied instantaneously.

### Cloud-Init & Custom Images
Automate server bootstrapping with SSH keys, user-data scripts, and Cloud-Init templates. Upload your own hardened qcow2, raw, or ISO images for full compliance.

### Full REST API & CLI Automation
Treat your infrastructure as code. Provision VMs, attach volumes, and manage firewall rules programmatically via our RESTful API and DevOps tool integrations.

## 6. Frequently Asked Questions (SEO Schema Ready)

**Q: How fast are ConnectVM virtual machines provisioned?**
A: Standard Linux virtual machines deploy and become reachable via SSH in under 45–60 seconds.

**Q: Can I keep my Public IP address if I delete or replace my VM?**
A: Yes. On ConnectVM, Public IPs are reserved to your account as independent network resources. You can detach a Public IP from one VM and attach it to another at any time without losing the IP address.

**Q: Is my data safe if a physical hardware node fails?**
A: Yes. ConnectVM uses distributed, triple-replicated block storage. Every write is synchronously replicated across multiple separate storage nodes, protecting your data against hardware drive or server failures.

**Q: Can I upgrade my VM resources or storage as my traffic grows?**
A: Absolutely. You can resize your VM's vCPU and RAM plan or expand your attached block storage volumes directly from the ConnectVM dashboard.

**Q: Do I get full root or administrator access?**
A: Yes. Every Linux VM includes full `root` / `sudo` SSH access, and every Windows VM includes full Administrator RDP access, along with an out-of-band web VNC console for emergency recovery.
