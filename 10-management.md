## 2. Four Ways to Manage Your Infrastructure

**Eyebrow:** BUILT FOR ADMINS & DEVOPS ALIKE
**H2:** Manage Your Cloud Your Way

### 1. ConnectVM Single-Pane-of-Glass Web Console
A fast, modern web dashboard designed for clarity—not clutter:
- Provision VMs, attach NVMe volumes, manage VPC subnets, and remap **Public IPs** in seconds.
- **Visual Network Topology:** View your virtual routers, private subnets, and connected instances clearly.
- **Out-of-Band HTML5 VNC Console:** Access any VM directly in your browser with full keyboard and screen control—even if the OS network stack is offline.

### 2. Comprehensive RESTful API & CLI
Every action available in the ConnectVM Web Console is backed by a documented, standards-compliant REST API and Command-Line Interface (CLI):
- Script automated instance scaling, snapshot schedules, and **Public IP** failover cutovers.
- Integrate directly into internal developer portals and custom billing/provisioning workflows.

### 3. Infrastructure as Code (Terraform, OpenTofu, Ansible, Cloud-Init)
Treat your infrastructure like application code:
- **Declarative Provisioning:** Define your VPC networks, Security Groups, Block Volumes, and Compute Instances in version-controlled templates.
- **Zero-Touch Bootstrapping (Cloud-Init):** Pass YAML user-data or startup scripts to configure packages, users, certificates, and Docker containers automatically on first boot.

### 4. Multi-Project Governance, Quotas & RBAC
Built for agencies, MSPs, and multi-team enterprises:
- **Project Isolation:** Segment departments, clients, or environments (`Prod`, `Staging`, `Dev`) into isolated projects with dedicated resource quotas (vCPUs, RAM, Storage GBs, Public IPs).
- **Role-Based Access Control (RBAC):** Grant fine-grained permissions to developers, network admins, and billing managers.
