## 3. Core Technical Features

### True Hardware Virtualization (KVM)
Every ConnectVM instance runs with strict kernel-level hardware isolation. Load custom Linux kernel modules, run Docker or Kubernetes clusters, configure WireGuard/IPsec tunnels, and enforce custom security policies without container-level limitations.

### Sub-Minute Provisioning & Cloud-Init
Automate instance bootstrapping at launch. Pass Cloud-Init user-data scripts, inject SSH keys, configure hostnames, and trigger Ansible or bash provisioning scripts automatically on first boot.

### Custom OS Images & ISO Mounting
Choose from our verified library of Linux distributions (Ubuntu, Debian, AlmaLinux, Rocky Linux, CentOS, Fedora) and Windows Server editions—or upload your own hardened `qcow2`, `raw`, or bootable `ISO` images.

### Server Groups: Affinity & Anti-Affinity
Control how your VMs are placed on physical hardware:
- **Anti-Affinity:** Automatically place redundant web nodes or database replicas on separate physical servers so a single hardware fault never takes down your cluster.
- **Affinity:** Co-locate tightly coupled compute nodes to minimize inter-node network latency.

### Live Lifecycle Control & Out-of-Band Console
- **Vertical Scaling:** Resize vCPU and RAM allocations as your workload grows.
- **HTML5 Web VNC Console:** Access your server's screen and keyboard directly through your browser for emergency recovery, even if SSH or internal networking is down.
- **Rescue Mode & Rebuild:** Boot into a temporary recovery OS to repair filesystems or re-image a server while retaining its assigned IP addresses.
